256 x 256 PNG files and renamed; the artwork itself is unchanged.

Mac file types (Pages, Numbers, Keynote, Mail, Calendar, Contacts, apps, ICNS, PLIST,
aliases and unknown files) are not included here: EchoNyla shows them with the
artwork macOS itself provides on this Mac.
