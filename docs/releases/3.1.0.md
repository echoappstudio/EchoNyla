## EchoNyla 3.1.0

A smarter on-device model that looks at your files, gives them proper names and sorts them by itself when it's sure.

- **Bonsai, a model that sees.** Turn it on in Settings → On-device model: EchoNyla downloads Ternary Bonsai 2 9B (about 3.2 GB, once) and runs it inside the app. It looks at screenshots, photos, PDFs and document previews, not just their names. It uses memory only while it's sorting and lets go after a minute. Nothing leaves your Mac.
- **Proper names, automatically.** Files whose names say nothing, like "Screenshot 2026-10-27 at 9.41.02 AM" or "IMG_4821", get a real name when Bonsai is sure, built from what's in them: "2026-10-27 Verbyn settings - Signature skin.png". Pictures keep their date first. Files with good names are left alone, and every rename can be undone.
- **Sorting it can stand behind.** Before a file goes into a folder, Bonsai has to quote the words in that folder's note that the file matches. No true quote, no move.
- **Check This Folder.** In Folders & Rules, Bonsai looks through a folder and moves out files that clearly belong elsewhere, renames the ones with useless names, and lists anything it isn't sure about.
- **Undo All.** Each batch of changes shows in Activity with one button that puts it all back.
- **Test on My Files.** Bonsai tries the files you've already sorted, shows how often it was right, and sets how sure it must be before it moves anything by itself.

Apple Intelligence is still there as the other choice, and everything works with AI off.
