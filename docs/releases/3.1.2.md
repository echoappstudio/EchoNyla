## EchoNyla 3.1.2

Fewer files land in the wrong folder, and Test on My Files gives a fairer score.

- **Learning from your moves is stricter.** EchoNyla used to move a file by itself once three files you'd moved shared any word with it, even three different words. Now the same word has to be in three files you moved to that folder ("Acme" in three Acme files). Words like "edited", "before" and "after" no longer count.
- **Screenshot names don't steer Bonsai.** Past moves of files named like "Screenshot 2026-10-25 at 12.33.39 AM" are no longer shown to Bonsai as examples. They only said "screenshots went there", which pulled every screenshot into one folder.
- **Suggested new folders must be named after their files.** A new folder Apple Intelligence suggests in Clean Up needs a name that appears in most of its files, like a client or trip name. Made-up names for files that only look alike are dropped.
- **A fairer test.** In Test on My Files, a file that has an exact copy in the folder Bonsai named counts as right, and copies of the file being tested ("… (2).png") are left out of Bonsai's examples. The report shows how sure Bonsai was about each miss, which folders it mixes up, and its highest score when nothing was sure.
