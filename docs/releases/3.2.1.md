## EchoNyla 3.2.1

Bonsai works faster, files can be previewed, and Quit is easy to find.

- **Faster Bonsai.** It keeps your folders and its instructions in memory instead of reading them again for every file, writes a shorter answer, and checks the answer's format the quicker way llama.cpp's own tools do. Screenshots and photos get a smaller picture, and PDFs and documents whose words were already read go without one. Deep Reorganize, Check This Folder and Learn From Its Files read the next file while Bonsai works on the current one. Exact copies of a file already done in a Deep Reorganize run aren't asked about again; they're listed with the duplicates.
- **Better text from pictures.** Text in screenshots and scans is read with Apple's accurate setting.
- **Previews.** Click a file's icon or name anywhere in EchoNyla for a Quick Look preview (or press Space while the pointer is on it). Double-click opens it. Rest the pointer on it for a larger picture.
- **Quit button** at the bottom of the window's sidebar and beside Open EchoNyla in the menu-bar panel.
- **Opening the full window puts the menu-bar panel away**, so it no longer sits in front of the window. Otherwise the panel still stays in front until you close it.
- **Test on My Files is gone.** The bar for moving by itself is back to 80%.
