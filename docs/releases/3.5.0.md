## EchoNyla 3.5.0

More careful with your files, and Files is now a place to look through your pictures.

### Suggest-only, if you want it
- **New setting: Rename files it's sure about by itself.** Turn it off along with "Move files it's sure about by itself" and EchoNyla only suggests: nothing is moved or renamed until you approve it.
- **Check This Folder lists files instead of moving them** when moving by itself is off.

### Learns less, guesses less
- **Folder habits need real evidence**: at least 3 files in a folder, and only words that show up more than once.
- **Past moves only count when they're about the same thing** as the file being sorted.
- **A new name has to come from the file.** At least half its words must be in the file itself, so made-up names don't get through.

### Folders and pictures in Files
- **Folders open inside EchoNyla**, not in Finder: double-click, Open, or the right-click menu. Show in Finder is still there.
- **Select a folder to see its newest pictures** in the preview pane. A folder that only holds folders, like Pictures with an album per trip, shows the newest pictures from inside them.
- **Small, Medium and Large icons.** Large shows photos big enough to recognize without opening them.
- **Fits narrow windows**: the toolbar shrinks instead of cutting off the sides.

### Search
- **Finds photos and recordings by what EchoNyla saw or heard in them**, like “dog beach”, in Find and in a folder's search.
- **Each result says why it came up**, like “Name has ‘dentist’ · EchoNyla saw ‘invoice’”.
- **No more made-up filters.** A file type, dates, screenshots or a website are only searched for when your words ask for them. Searching “rocks” no longer turns into “documents from the last two months”.

### Clearer names
- **Recordings and videos start with the day they were made**, like photos.
- **PDFs and documents start with the month of the first date written in them**, like `2026-03 Acme Plumbing invoice.pdf`. No clear date, no date.
