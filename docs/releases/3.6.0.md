## EchoNyla 3.6.0

Faster with big folders, and the Files page works more like Finder.

### Faster
- **Big folders open in about 2 seconds.** A folder with 20,000 files used to take 8 to 10.
- **Pictures stop flickering** when you scroll through a big folder.
- **Watching does less work.** macOS tells EchoNyla when a file arrives, so it no longer checks your folders every 4 seconds.

### More like Finder
- **Rename in the list.** Press Return and the name turns into a text box with the part before the extension selected. New folders (⇧⌘N) start the same way, as "untitled folder".
- **Type to jump.** Type the first letters of a name and the list goes there.
- **Drag several files at once** to Finder, Mail or any other app.
- **⌥⌘V moves** the files you copied into this folder, and **⌥⌘C** copies their paths. Copy Path is in the right-click menu too.
- **Hidden files** show up dimmed with ⇧⌘. (also in the Group menu).
- **Quick Look steps through the folder.** Press Space, then the arrow keys, and the selection follows along.
- **Finder tags** show as colored dots next to names and in the preview pane.

### Clearer suggestions
- **Every suggestion says where it came from:** your rule, a screenshot, your past moves, or Apple Intelligence.
- **Undo teaches it.** Undo a move EchoNyla made by itself, and files like that one wait for you next time. Settings has a button to forget these.
- **It learns from websites.** Move 3 files from the same website into one folder and the next one from there is suggested for it. Mail, cloud drives and file-sharing sites don't count.

### Shortcuts and Finder
- **New Shortcuts actions:** Sort Files, What Is This File?, Find Files, Show in EchoNyla and Clean Up Downloads. You can also ask Siri to "Clean up Downloads in EchoNyla".
- **Right-click files in Finder** and pick Services to find Sort with EchoNyla and Show in EchoNyla.

### Fixes
- Starting a search while another was still running could leave the first one stuck.
- Names and descriptions no longer show "#####" where EchoNyla hid a long number.
- Dates in the Files list no longer wrap onto two lines.
