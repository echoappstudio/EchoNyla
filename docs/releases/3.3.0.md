## EchoNyla 3.3.0

EchoNyla now runs on Apple Intelligence alone, and it does everything Bonsai did.

- **Apple Intelligence only.** Bonsai and its engine are gone, so the app is smaller. Its 3.2 GB download is deleted from EchoNyla's own folder the first time 3.3.0 opens.
- **Deep Reorganize, Check All Folders and Learn From Its Files** work with Apple Intelligence.
- **Better answers.** Apple Intelligence gets the same instructions Bonsai had: keep a name that already says what the file is, and never make up details. It scores how sure it is about each name and folder from 0 to 100. Folders are chosen from your list only, spelled exactly. Answers pass the same checks before anything moves.
- **It reads more of each file.**
  - On macOS 27 it looks at a picture of screenshots, photos, scans and documents whose words don't say enough.
  - It sees the people, places and companies a file names, and its language.
  - It listens to the first minute of voice memos, recordings and videos. This happens on this Mac, and only when Look inside files is on.
- **Faster batches.** Apple Intelligence is warmed up before a batch. The next file is read while it works on the current one, and exact copies skip it.
- **Names count as sure a little sooner.**
  - **75% or more:** a name built from what's in the file is sure. It's checked for you and included in Approve All. It's applied by itself only when the old name said nothing, like `IMG_4821`.
  - **50% to 74%:** the name is listed as "not sure", with its own Approve All in Clean Up and Deep Reorganize.
  - **Activity:** "Waiting for you" has an Approve All for names.
- **Files already handled are skipped.** Deep Reorganize and Check This Folder skip files they already named, and files you approved or left as they are, until the file changes. Look at All Files Again starts over. Deep Reorganize has a Leave As Is button.
