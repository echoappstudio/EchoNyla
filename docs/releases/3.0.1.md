## EchoNyla 3.0.1

Clean Up now works on the folder you choose.

- **The main button follows your folder.** It says Clean Downloads, Clean Documents or the name of whichever folder you picked, and cleans that folder.
- **Choose Folder is a short menu.** Downloads, Desktop and Documents are always there, then the last few folders you cleaned, then Other Folder… for any other one.
- **Clean Up remembers your folder.** After you quit and reopen EchoNyla, Clean Up starts on the last folder you cleaned.
- **Fixed: switching folders needed a second pick.** Picking a new folder while Apple Intelligence was still looking at the last one showed the files but no suggestions. Apple Intelligence now starts on the new folder straight away.

Watching Downloads for new files is unchanged: it keeps running whichever folder Clean Up shows.
