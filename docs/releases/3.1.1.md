## EchoNyla 3.1.1

Bonsai picks folders better and gives cleaner names, after the first real test.

- **Better folder picks.** Bonsai now sees how you filed similar files before, and it's no longer told that most files fit no folder. The safety net stays: it still has to quote the folder's note before anything moves.
- **A slightly lower bar.** Bonsai moves a file by itself at 80% sure (was 85%); clearly right answers were coming in at 80%. Test on My Files still raises it if its sure answers aren't right often enough.
- **Cleaner names.** File names Bonsai reads inside a screenshot no longer leave their extension in the new name ("Congrats (Purevo).wav.png" is now "Congrats (Purevo).png"). Names like "Purvo-with-hvac-1080p" become plain words, and a name one letter off a word EchoNyla already knows, from your folders, their notes or the file itself, is spelled right ("Pureo" becomes "Purevo").
- **A clearer test report.** Test on My Files lists the files where Bonsai's folder differed from yours, and says so when it wasn't sure enough about any file to move it.
