## EchoNyla 3.0.0

Levant is now **EchoNyla**: a new name, Echo App Studio's Signature look, and several new ways to file things faster.

- **A new name.** EchoNyla is a fresh start: it doesn't bring over Levant's settings, folders or history. Delete Levant, then set up EchoNyla in a minute (below). macOS asks again for Downloads, Desktop and notifications.
- **Signature look.** Black and silver, light or dark with your Mac, with a new icon and menu-bar picture. Choose from the same six skins as Verbyn (Signature, Sky, Green, Turquoise, Bordeaux, Wisteria), each light and dark; the icon follows the skin.
- **Drop on a folder.** The menu-bar panel shows your favorite folders as tiles. Drop a file on one and it goes straight there, with Undo. Drop it below the tiles to let EchoNyla sort it, as before.
- **Set up in a minute.** EchoNyla suggests favorite folders from the ones you already use in Documents and on the Desktop, each with a note saying what goes there, drafted by Apple Intelligence. Nothing is added until you tick it.
- **Learns from Finder.** When you move a new download into a favorite folder yourself in Finder, EchoNyla learns from it, just as when you click Move.
- **Clean Up sorted by how sure it is.** Files are split into Sure, Guesses and No idea, with one button to approve every sure move. Every file can go to **Any Folder…**, not only a favorite.
- **A weekly Downloads reminder.** A quiet row in the panel when Downloads has five or more files over two weeks old. Dismiss it for a week, or turn it off in Settings.
- **File type icons.** Every file shows what it is: Word, PDF, Photoshop, MP3 and over a hundred more, with Pages, Keynote and other Mac types drawn by macOS itself. Unknown types show their letters.
- **Smaller things.** ⌘1 to ⌘5 switch pages, the Apple Intelligence mark takes the skin's colours, and the panel remembers your Rename choice.

Nothing is ever deleted, and every move and rename can still be undone.
