## EchoNyla 3.2.0

Deep Reorganize, and folders Bonsai learns from what's already in them.

- **Deep Reorganize.** A new page. Pick one or more folders to go through, and any folders to leave alone. Bonsai looks at every file in them (about 9 seconds each, in the background, with Pause). Files it's sure about get a clear name and move into your Sort-into folders by themselves; the rest wait on the page with its ideas. Undo All puts the whole run back, even after a relaunch.
- **New folders from what files have in common.** After a run, files Bonsai couldn't place that are about the same thing (an app, a client, a trip) are offered as a new folder, judged by what's in them rather than similar names. Nothing is made until you check it.
- **Exact duplicates.** Files with exactly the same contents are listed together, whatever they're called, so you can put the extra copies in a Duplicates folder. A "(2)" in a name means nothing on its own: two screenshots taken at once on two displays are different pictures.
- **Sort into this, or Just for dragging.** Every favorite folder is one or the other. Only Sort-into folders get files from Bonsai or Apple Intelligence; the others are quick places to drop things. Folders with a note keep working as before.
- **Bonsai learns your folders.** It looks at up to 12 files already in a Sort-into folder and writes down what they are, plus a short note (your own note is kept). Suggest Folders does this for each folder you add.
- **A new safety net.** A file moves by itself only when Bonsai is at least 80% sure and what's in the file matches that folder better than any other. Two folders that fit equally well means it asks you. This replaces quoting the folder's note, which failed on nearly every real file. Apple Intelligence now has to pass the same check.
- **Zips are named after what's inside them**, read from the zip's table of contents without unpacking it.
- **Test on My Files** only uses Sort-into folders and has a Copy Details button with every answer in plain text.
